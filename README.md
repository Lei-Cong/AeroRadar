# AeroRadar 原型

一个桌面浏览器中的实时飞行雷达。它读取公开 ADS-B 数据，以用户位置为中心显示附近飞机、航班号、高度、速度、航向、距离与短时轨迹。

默认地址框预填 `Hinter der Kapelle, 55128 Mainz` 作为示例。使用者可以输入自己的街道、城市或邮编，也可以使用浏览器定位；应用不固定于任何私人地址。

## 可行性与数据源

这个产品在技术上可行，但公开 ADS-B 数据不是航空管制数据：覆盖取决于志愿者接收站，可能延迟、缺失或隐藏部分飞机，航班号也不等同于完整的出发/到达计划。

- **当前默认：ADSB.lol**。无需密钥，提供按经纬度与半径查询的 v2 接口，适合快速原型。公开数据采用 ODbL；生产使用前应确认条款、署名方式与服务稳定性。
- **备选：OpenSky Network**。研究与非商业用途成熟，支持状态向量和边界框查询，但匿名额度较低；正式应用建议通过 OAuth2 在服务端认证。
- **生产方案**。若需要商业 SLA、稳定航班计划或始发/目的地，应另行接入商业数据供应商，并保留 ADS-B 作为实时位置层。

## 架构

浏览器获取用户授权的位置 → 同域 `/api/aircraft` 代理 → ADSB.lol 邻近飞机接口 → 标准化单位和字段 → 15 秒刷新雷达。实时源不可用或附近无数据时，接口返回明确标注的演示样本，让交互仍可体验。轨迹只在当前页面内存中累积。

手动输入地址时，同域 `/api/geocode` 会把查询转发给 OpenStreetMap Nominatim 并返回近似坐标；应用不建立地址数据库。公开部署前请遵守 Nominatim 使用政策，流量较大时应更换为自建或商业地理编码服务。

## 隐私

- 定位必须由浏览器明确授权；拒绝后继续使用当前地址或 Mainz-Bretzenheim 示例位置。
- 默认示例位于 Mainz-Bretzenheim；地址输入可由使用者覆盖。
- 手动输入的地址会发送给 OpenStreetMap Nominatim 用于地理编码，但不会由本应用保存。
- 坐标仅用于向同域接口发起邻近查询，不写入数据库，也不使用分析追踪器。
- 上游服务会收到查询中心的大致坐标和常规网络信息。生产版可把坐标量化到较粗网格、缩小日志保留并提供显式隐私设置。
- 本工具不是航空导航或安全关键系统。

## 本地运行

要求 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建使用 `npm run build`。

## 已实现的最小版本

- 浏览器定位与拒绝授权回退
- 2 / 5 / 10 / 20 / 50 / 100 海里雷达范围
- 实时/演示数据状态、15 秒自动刷新、手动刷新
- 飞机选择与航班号、高度、速度、航向、距离、升降状态
- 页面会话内短时轨迹、响应式桌面/移动布局、减少动画偏好
- 默认观测区域为 Hinter der Kapelle 附近的街区级中心点，不包含门牌号
- 根据本地典型时段与实时低空航迹推断 BR 07 / BR 25，并显示今日头顶繁忙度趋势；该趋势属于模型估算，不是航空管制预报
- 雷达为每架飞机显示最近约两分钟的细虚线渐隐尾迹，旧线段会自动淘汰，轨迹仅存在于当前页面内存
- 繁忙度预测按 00:00–23:00 的每个整点显示指定地址附近预计飞机数（架/小时）
- 统计半径可在 1–50 km 内自定义，默认 5 km，并仅保存在当前设备
- 当前时段由访问者设备的本地时间决定，并每分钟同步，避免服务器 UTC 时区造成偏移
- 当前小时使用唯一的绿色“现在”标记，其他小时保持灰色
- 实时源短暂失败时保留上一批真实飞机；短暂丢失的飞机保留最多 60 秒，避免数量剧烈跳动
- 使用 ADSBDB 按广播航班号补充出发地和目的地机场代码；查不到时保持原航班号，不影响雷达
- 根据 ICAO 机型代码显示客机、大型宽体机、小型飞机或直升机图案
- 校正图案基准角：航向 0° 指向雷达正北、90° 指向正东，渐隐轨迹位于机尾方向
- 图标方向优先使用最近两个位置点计算，使机头沿实际航迹延长线；无有效轨迹时回退到 ADS-B 航向
- 雷达下方提供客机、小型飞机、直升机、轨迹和观测点图例
- 根据观测地址和当前显示范围读取 OpenStreetMap 跑道数据，在雷达中以半透明图层显示真实位置、长度方向和跑道编号
- 跑道图层默认仅显示有编号且长度不少于 1,200 米的主要跑道，也可切换为显示全部小型或未编号跑道
- 跑道查询在多个 OpenStreetMap Overpass 服务之间自动切换，短暂失败时保留上次成功结果并显示状态
- 支持中文、德语和英语界面，语言偏好仅保存在当前设备
- 小型飞机使用固定朝北的 CSS 图形，并从最近多个有效位置点计算航向，避免字体角度和重复坐标导致机头反向
- 首屏立即显示明确标注的演示目标并连接实时 ADS-B，连接成功后无缝替换；短时缓存降低重复访问等待
- 航班号使用关闭连字的等宽字体，避免 BEL9DN 等字母数字组合出现宽度或基线错位
- 小型飞机改为与客机相同的图标并缩小显示，不再使用容易被看成箭头的简化轮廓
- 最近一次成功的实时位置和飞机数据在当前设备保留最多 15 分钟；再次打开时立即恢复，并在已有定位授权时自动刷新当前位置
- 雷达下方提供三语的 Raspberry Pi + RTL-SDR 本地 ADS-B 接收技术说明，解释 1090 MHz 数据链路、实时性和覆盖限制
- 小型飞机使用方向稳定的单色轮廓；带地面标记或同时低速、低高度的已降落飞机立即从雷达隐藏
